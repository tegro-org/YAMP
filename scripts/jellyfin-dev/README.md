# Local Jellyfin for development

A Jellyfin server in Docker with a few free test albums, for developing and testing YAMP's Jellyfin provider on the
emulator (docs/phase-3-providers.md step 18, D85). Your own server is never used for development; no server
address, user name or password goes into this repository.

## Use

```sh
scripts/jellyfin-dev/setup.sh      # fetch the test music (first run), start the server, finish its setup, scan
docker compose -f scripts/jellyfin-dev/docker-compose.yml down   # stop it (data stays)
rm -rf scripts/jellyfin-dev/data   # forget everything (server config, test music, dev password)
```

- On this machine: <http://localhost:8096>. From the Android emulator: `http://10.0.2.2:8096`.
- User `yamp-dev`; its password is generated on the first run and kept only in `data/dev-credentials`.
- Quick Connect is switched on, for the app's Quick Connect sign-in.
- Plain HTTP: the emulator reaches the host directly. HTTPS with a local certificate is not set up (the app's
  debug build allows clear text to `10.0.2.2` once sign-in lands, step 21).
- Everything the server writes lives in `data/` (gitignored). `setup.sh` is safe to run again.

## Test music

`fetch-test-music.sh` downloads six tracks by **Kevin MacLeod** from [incompetech.com](https://incompetech.com),
licensed **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**, and arranges them as two albums under
`data/media/Kevin MacLeod/` (about 55 MB, plus 35 MB of downloads it keeps to avoid fetching again):

| Album | Tracks | Format |
|---|---|---|
| YAMP Test MP3 | Sneaky Snitch, Carefree, Local Forecast – Elevator | MP3 as published (320/256 kbps, 44.1 kHz), re-tagged |
| YAMP Test FLAC | Fluffing a Duck, Monkeys Spinning Monkeys, Wallpaper | FLAC 16-bit transcoded from the MP3s — one at 48 kHz, two at 44.1 kHz — with an embedded front cover |

Attribution, as the licence asks: "Sneaky Snitch", "Carefree", "Local Forecast – Elevator", "Fluffing a Duck",
"Monkeys Spinning Monkeys", "Wallpaper" — Kevin MacLeod (incompetech.com), licensed under Creative Commons:
By Attribution 4.0 License. The FLAC files are transcodes made for testing (format, sample rate and cover handling),
not better-quality copies. The cover image is generated by the script.

Needs: Docker with Compose v2, `curl`, `ffmpeg`, `python3`.
